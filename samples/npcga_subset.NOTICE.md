# NPCGA subset — source, license, and changes

`npcga_subset.csv` demonstrates the connector on a real, openly-licensed apparel
file with per-item fibre composition and weight (BACKLOG.md item 7;
`scripts/npcga_footprint.py`). It is included under the source's license, separate
from this repository's Apache-2.0 code.

- **Source:** Pettersen, Johan Berg; Aarak, Solveig; Peña Benítez, Vanessa;
  Nourin Moury, Nazia. *Norway post-consumer garment data and images: 16 464
  clothing samples from donations and discards* (2026), file
  `NPCGA_datatable_1.1.csv`.
  [Zenodo 10.5281/zenodo.20440761](https://doi.org/10.5281/zenodo.20440761).
- **License:** Creative Commons Attribution-ShareAlike 4.0 International
  (**CC BY-SA 4.0**). This file, and any adaptation of it, remain under CC BY-SA
  4.0; the surrounding code is Apache-2.0 (mere aggregation, not an adaptation of
  the data).
- **Changes:** row subset only — the header and the first 200 data records of the
  published table, otherwise unchanged (semicolon-delimited as released).
- **Retrieved:** 2026-09-17.
